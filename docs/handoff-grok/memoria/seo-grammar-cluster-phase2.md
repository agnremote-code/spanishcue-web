Phase 2 of the SEO work ("SEO y crecimiento orgánico" thread) is the teacher grammar cluster under `/spanish-grammar-lessons`. Codex shipped the base in PR #139 (merged 2026-10-07, live): hub, level pages `/spanish-grammar-lessons/{a1..c1}` (no C2 page on purpose: only one C2 classroom), four activity kits (ser/estar, preterite/imperfect and subjunctive rendered on their existing `/guides/*` URLs; por/para at `/spanish-grammar-lessons/por-vs-para-activities`) and `/about` with Preply-sourced proof (rating 5/52 reviews, 4,000+ lessons, three named student quotes; Ale's brief said "do not invent reviews/testimonials", these are sourced, flagged for Ale's confirmation). Claude extended it on 2026-10-12 in branch `claude/seo-grammar-cluster-20261012` (PR #163, opened as a draft on 2026-10-12; Ale never marked it ready, so on 2026-10-14 its commits shipped inside PR #192, main 400ebfc, production deploy + smoke green at 18:26Z; #163 closed as merged): kits for conditional/si clauses (new URL `/spanish-grammar-lessons/conditional-tense-activities`, classrooms 146, 31, 214, 219, 23, 152), imperative (`/guides/spanish-imperative-activities`, 145/213/148) and object pronouns (`/guides/spanish-direct-indirect-object-pronouns`, 106/46/114); hub H1 "Spanish grammar activities for teachers that turn a rule into a real conversation"; level pages link the kits of their level; guides index and marketing-landing footer link the hub and About; anonymous edge cache for organic HTML in `worker/index.ts` (`isEdgeCacheablePath` allowlist, cookie/`?lang=`/RSC/Authorization bypass, key = deployment + build id from Vite `define` `GITHUB_SHA`, 600 s TTL, `X-SpanishCue-Cache: HIT|MISS`, browsers get `public, max-age=0, must-revalidate`). Search Console (Jul–Oct 2026) showed almost no traffic: grammar hub 21 impressions at position 11, 3 clicks site-wide; legacy `?lang=` URLs still listed as separate pages.

**Why:** Ale asked for a second organic authority cluster (grammar for teachers) built on real lessons, no duplicate URLs, no blind deploys, and asked to spend few credits.

**How to apply:** Add a grammar kit as a data entry in `app/growth/grammar-topics.ts` (3 activities: steps ≥3, prompts ≥2 in neutral tú Spanish, model, correction, adaptation; title ≤65 chars; description 110–165 chars; unique activity names across levels and kits, enforced by `tests/grammar-seo.test.mjs`), add its slug to the relevant `topicSlugs` in `app/growth/grammar.ts`, extend the `owned` list and `paths` in `tests/grammar-seo*.test.mjs`; sitemap and static params derive from the data. Upgrade an existing guide instead of creating a sibling URL (set `lastReviewed`). The content queue and cannibalization warnings live in `docs/seo-strategy.md` §11. Keep the conversation cluster copy untouched until it has 90 days of data. Related: [[seo-foundation-pr126]], [[spanishcue-overview]].
