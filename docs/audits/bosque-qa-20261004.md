# Giant mushroom forest verification

Author: Codex. Base main: `199f0f1eaae8209baf8569630dc257f08856dc9c`.
Scope: one protected lesson, route `/bosque-de-los-hongos-gigantes`, catalog ID 226.

## Implemented and checked

- Six independent authored banks, 72 prompts each (432 total), 12 categories and all 14 prompt types. Direct lexical ES–EN glosses for A1–B2; no automatic glosses for C1/C2. No answer key, score, recording or runtime TTS.
- Actual Three.js forest: 63 physical platforms, branching side paths, 12 conversation refuges, stream, waterfall, cave, trees, foliage, canopy and crown. Deterministic 90 Hz traversal simulations reach all 63 platforms and all 12 zones.
- Official mascot references were inspected. There is no rigged brand model in the repository. The hero uses an original, identity-referenced directional animation atlas and a separately animated segmented 3D cape. This is a hybrid, not a claimed rigged GLB character.
- Physics checks cover running, jumping, landings, bounce and checkpoint respawn. Session checks cover nonrepeating/exhausted decks, independent levels, final unlock, resumed final questions and completion.
- Actual React DOM interaction checks cover every level query and invalid fallback, choices and oral justification, gloss visibility, follow-ups, same-level preservation, switching-level reset, focus after card replacement, Tab containment, Escape and actual WebGL-constructor failure fallback.
- Independent review found and prompted fixes for dialog focus after replacement, nonexistent saved prompt IDs and same-level progress reset. Map focus containment and guide Escape also corrected.
- Existing catalog snapshot helpers remove only the exact new record, route ID, count increments and test dependency additions before comparing historical snapshots. No existing baseline hashes were replaced.
- English guard permits only exact path/text pairs for the requested new glosses. Changed/deleted English remains blocked. Two exact first-person preterite examples have contextual neutral-Spanish exemptions.

## Visual verification limits

Responsive styles exist for wide desktop, 1366, 1024, tablet, 390 and 320 widths, with lower renderer cost and touch controls on coarse pointers. These widths are not claimed as browser-verified screenshots.

Local browser installation failed: the browser archive host returned a 195-byte “Site Unavailable” response instead of an archive. The available cloud browser cannot open the local QA server (`ERR_BLOCKED_BY_CLIENT`). Therefore rendered 3D quality, moving-cape appearance, real-device joystick behavior and viewport layout inspection remain unverified. DOM tests and deterministic physics tests do not substitute for that visual inspection. Production authentication is unchanged.
