# Clases 3D semanales: creador + crítico

Ale (2026-11-04): every week two NEW 3D conversation classes go live, each on a
topic no existing class covers, each better than the last. One agent creates,
another critiques, and they talk until it ships. No loops: at most TWO critique
rounds, then the class is published no matter what (open issues go to
`LECCIONES.md` for next week).

Read `LECCIONES.md` before starting. It is the memory of the system: every
week adds what the critic caught and what worked.

## Roles

1. **Creador** (one per class). Builds the whole class on its own branch
   `claude/escucha-3d-<slug>` (that prefix triggers the Escucha 3D audio
   workflow, which commits the mp3s back to the branch).
2. **Crítico** (independent agent, gets the code, not the creator's opinion).
   Plays/reads the class and returns a ranked list: BLOQUEANTE (must fix),
   MEJORA (should fix), IDEA (next week). Round 2 checks only that round 1
   was fixed plus anything new and serious.
3. **Orquestador** (the thread). Picks topics, runs the rounds, runs
   `npm test`, opens the PR, verifies merge + deploy, writes the lessons.

## Choosing topics

- `grep -oE 'title:"[^"]+"' app/lesson-catalog.ts` and the backlog below:
  the topic must not repeat any existing class (3D or classic).
- The two classes of a week must differ in tone and setting (e.g. a mystery
  and a celebration, a city and nature).
- Backlog of approved ideas (Ale, 2026-10-31): ~~El tren de las 23:40~~,
  ~~La boda~~, La casa (reality show, confessional), Último crucero (ship in a
  storm). After the backlog, invent new ones in the same spirit: one place, one
  night/day, 18 scenes with a person who has a problem, black humour allowed,
  real-life Spanish.

## What a class is (copy the newest world as the template)

Template: the most recent 3D world (start from `app/el-consorcio/`, ID 245,
PR #325; check later ones in LECCIONES.md). A class has:

- `app/<slug>/`: page.tsx, layout.tsx, Game, World3D, the 3D scene (`*3d.ts`,
  items), engine, story (18 scenes), NPC cast (~17 extra people with their own
  conversation at three levels), `levels/a0..c2.mjs` (each level genuinely
  authored: 3 answers with consequences + 5 talk questions per scene; A0
  bilingual, A1 glosses key words, C1/C2 Spanish only), ambience/music,
  css, `.d.mts` files.
- Listening: `app/escucha-3d/content/<game>/a0..c2.json` (18 per level = 126),
  registered in games.mjs/.d.mts, loaders.ts, types.ts, scripts/check-escucha-3d.mjs.
  Audio is generated by the workflow on push; `tests/escucha-3d*` fails locally
  until that commit lands, so open the PR only after it.
- Wiring: app/lesson-catalog.ts (entry + Conversación order list, `news`
  with today's date), app/academias/page.tsx, app/api/live-class/route.ts
  (world IDs), app/resource-seo.ts + tests/fixtures/published-resource-slugs.json,
  app/conversation-preview-videos.ts + public/conversation-previews/<id>.mp4
  (10 s, H.264 640x360, < 400 KB, crf ~32), scripts/test-worker.mjs,
  tests/helpers/catalog-additions.mjs, tests/level-cleanup.test.mjs,
  tests/noche-abierta.test.mjs, tests/rendered-html.test.mjs counts,
  scripts/check-english-copy.mjs + `docs/audits/<slug>-english-additions-<date>.json`
  (cite Ale's standing approvals cmsg_01Gr5R4j3t2Yet65UcmhcVhADwvzg9kA9GinuWu3D7FSfe
  and cmsg_01Gr5R4j3t2Yet65UcmhcVhAAAbp6kqDfMqxzNm3PL6f5g; never self-approve),
  `scripts/check-<slug>.mjs`, `tests/<slug>.test.mjs`, and the world's floors in
  the WORLDS registry of `tests/3d-sin-fantasmas.test.mjs`.
- Cover: cartoon key art in the grammar-mascot doll style (never a game
  screenshot), art at `scripts/covers/art/<slug>.webp`, add it to WORLDS in
  `scripts/covers/render.mjs`, render to `public/<slug>/portada.webp`
  1200×750 < 120 KB. Canva `generate-image` with public/mascots/explorer.png as
  style reference if credits remain; otherwise draw it as an illustrated SVG/HTML
  scene in that style and render it (never a screenshot).

## Non-negotiable rules (Ale)

- Nobody inside an object, ever, cinematics included: `escapeSolids`/pushOut,
  WORLDS registry, plus the per-vertex browser check (see LECCIONES.md).
- Space = jump, N = nitro, touch buttons on mobile; people are solid and yell
  when bumped; shared music volume slider (`app/escucha-3d/MusicVolume.tsx`);
  charlas-3d circles on every NPC/landmark.
- No neon dashboards, no coins, no rankings, no score HUDs. Adult classes have
  no disclaimers.
- Neutral Spanish with tú in instructions (the guard flags voseo, even on signs).
- Large data never in the Worker bundle (outage 2026-11-02): keep total upload
  < 30 MiB; big content goes to assets. Check the build size.
- The levels are A0–C2, all seven, all authored.
- Run the full `npm test` locally before the PR (CI does not run it all).
  Shallow clones break tests: `git fetch --depth=2000 origin main`.

## Critic checklist

Language (natural, level-appropriate, no repeated questions from other
classes, questions that make the student talk a lot and feel personally
touched), story (each scene has a real problem and a funny/moving twist,
consequences differ per answer), 3D (ghosts, collisions, camera, mobile,
performance on low-end, readable signs), Ale's rules above, wiring and tests,
cover in the right style, and "is this better than last week's?".
