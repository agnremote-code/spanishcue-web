# docs/board — SpanishCue Executive Board records

Version-controlled institutional memory for the Executive Board (Alejandro, CEO; Sofia, CPIO; Martin, CLRQO). Read in this order:

1. [STATUS.md](STATUS.md): owner decisions in force, verified facts, backlog, routines and the next action.
2. [CONSTITUTION.md](CONSTITUTION.md): roles, decision rules, workflow, transparency and safety.
3. [ROUTINES.md](ROUTINES.md): the runbook every scheduled cloud run follows.
4. `decisions/`: locked decision documents, including recorded dissent.
5. `concepts/`: lesson concept rounds, chosen and rejected.
6. [PUBLISHED.md](PUBLISHED.md): what has been published to production, with evidence.
7. `evidence/`: data pulls, kept separate from interpretation.
8. `transcripts/`: verbatim inter-agent SendMessage archives (sender, recipient, UTC timestamp).
9. `assessments/`: weekly Friday assessments, once they exist.
10. [OWNER-MANDATE-2026-10-16.md](OWNER-MANDATE-2026-10-16.md): the owner's founding mandate.

Paths inside the decision files that start with `/private/tmp/...scratchpad/` refer to the original session's working copies. Their content is preserved here.
