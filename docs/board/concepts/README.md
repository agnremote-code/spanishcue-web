# Lesson concepts

One file per concept-selection round, named `YYYY-MM-DD-<slug>.md`. Each file records every concept proposed (by whom), the scores, the vote, the chosen concept and why, and the rejected concepts with their reasons. Rejected concepts stay here so later rounds don't re-propose them without new evidence.
