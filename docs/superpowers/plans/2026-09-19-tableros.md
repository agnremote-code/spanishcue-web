# Tableros Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crear dos Tableros PRO B1/B2, un motor compartido persistente y el contrato de integración para incorporarlos después al catálogo central.

**Architecture:** `app/boards/` encapsula tipos, motor, validación, bancos, UI y estilos. Las rutas B1/B2 son adaptadores mínimos; `catalog-adapter.ts` prepara entradas sin modificar catálogo o navegación compartidos.

**Tech Stack:** React 19, TypeScript 5.9, Next/Vinext, CSS, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-19-tableros-design.md`

## Global Constraints

- Mantener exactamente cinco categorías pedagógicas; Tableros es estilo de Conversación.
- Mantener PAÍSES separado y sin duplicados.
- B1 y B2 contienen cada uno 72 principales, 12 finales y dos repreguntas por principal.
- Exactamente 24 principales B2 contienen un cambio opcional de condición.
- Cero llamadas IA por clic y ninguna evaluación de opiniones.
- No modificar catálogo, navegación ni build central; entregar adaptadores para tarea 8.
- No merge ni deploy.

## Review Focus

- Estado persistido corrupto: se descarta o normaliza sin romper la clase.
- Categorías seleccionadas vacías: no puede comenzar una cola inválida.
- Banco agotado: no repite automáticamente y ofrece reinicio claro.
- Teclado dentro de un botón/control: no dispara una segunda acción global.
- Refresh después de retroceder o profundizar: conserva pregunta y subestado.
